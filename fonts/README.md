Fonts in this directory are variable-weight WOFF2 builds obtained from Google's font
directory (github.com/google/fonts), converted from the upstream variable TTFs with
`fonttools varLib.instancer`'s WOFF2 flavor (no instancing — the full weight axis ships
in each file). Each license is reproduced in the font's subdirectory.

- `InclusiveSans/` — variable weight 300-700, upright and italic.
- `Urbanist/` — variable weight 100-900, upright and italic.
